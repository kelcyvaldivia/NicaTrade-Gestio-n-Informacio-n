# Gestión Digital de Información para NicaTrade International

 Objetivo
Organizar e integrar la información relacionada con una operación de importación comercial desde México hacia Nicaragua utilizando herramientas digitales colaborativas.

Herramientas Utilizadas
* Microsoft Word
* Microsoft Excel
* Microsoft PowerPoint
* Google Drive
* GitHub
* Simulación de Gestión Documental (Alfresco)
